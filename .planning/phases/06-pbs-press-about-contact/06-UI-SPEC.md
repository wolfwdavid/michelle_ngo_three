## Typography

`_three`'s cinematic-immersive type system uses **two type families** with a clear role split: `--font-display` (Source Serif 4) for monumental moments (wordmarks, headings, blockquote, press network identity); `--font-sans` (Inter) for legible body + interactive surfaces; `--font-mono` (JetBrains Mono) reserved for the index/total caption on reel sections only.

### Type Ramp: 4 sizes total

Phase 6 declares **exactly 4 stock Tailwind font sizes** across the whole system — no responsive `md:` size escalations on display wordmarks. The cinematic scale is carried by viewport composition (`h-svh` sections + centered alignment), not by responsive type bumps.

| Token | Pixel size | Role |
|-------|-----------|------|
| `text-sm` | 14px | Eyebrow labels, CTAs, attribution captions, monospace index/total caption (absorbs the prior `text-xs` 12px usages — bumped up to 14px) |
| `text-base` | 16px | Body prose, blockquote body, bio paragraph, ContactBlock rows, Footer link rows, press title caption, Footer bottom strip (collapsed the prior responsive ramp `text-lg`/`text-xl`/`text-2xl` body uses to this single body size) |
| `text-2xl` | 24px | Mid-display tier — currently unused in Phase 6 visible composition; reserved for a future mobile-only display step if cinematic-scale tuning requires it during plan-phase. Declared so the ramp has a deliberate fourth tier and does not collapse to 3. |
| `text-6xl` | 60px | Primary display wordmarks — all full-bleed hero contexts. Single hero size, NO responsive bump. |

**Every entry uses a stock Tailwind utility — no custom font-size CSS, no arbitrary `text-[Npx]`.**

### Weight ramp: 2 weights total (global, all 3 font families)

Phase 6 declares **exactly 2 font weights total across the whole system** — not per-family. Both weights are loaded from existing project-level @theme assets (no new weight loads).

| Weight | Role |
|--------|------|
| 400 (regular) | Bio prose, blockquote body, ContactBlock rows, Footer link rows, Footer bottom strip, index/total monospace caption, attribution / metadata captions, **AND the press network wordmark** (dropped the prior 700 — at `text-6xl` display scale the 600→700 weight delta is below typographic perception thresholds) |
| 600 (semibold) | ALL display wordmarks (`ABOUT`, `MICHELLE NGO`, PBS section-zero h1, press network names — all unified at 600), eyebrow labels, CTA labels, sr-only `<h1>` landmark headings (consolidated all "emphatic non-body" contexts to 600 — dropped Inter weight 500 entirely; eyebrows + CTAs bump from 500 to 600, which is slightly more on-brand for the A24/MUBI/Criterion DNA anyway) |

### Contract rules

- **4 sizes total: `text-sm` (14px), `text-base` (16px), `text-2xl` (24px), `text-6xl` (60px).** No other size tokens permitted. Every entry uses a stock Tailwind utility — no custom font-size CSS, no arbitrary `text-[Npx]`.
- **2 weights total: 400 regular, 600 semibold — used across all 3 font families.** No weight 500 (Inter) and no weight 700 (Source Serif 4) in Phase 6. The project-level @theme decl may still load these assets for sibling-phase compatibility, but Phase 6 code MUST NOT reference them.
- **No responsive `md:` size escalation on display wordmarks.** All hero contexts (`ABOUT`, `MICHELLE NGO`, PBS h1, press network names) render at a single `text-6xl` across mobile and md+. Cinematic scale is carried by the `h-svh` viewport + centered alignment, not by responsive type bumps. This is a deliberate `_three`-specific posture (the editorial-modern sibling `_four` may use responsive bumps; `_three` does not).
- **Line height: 1.5 for body prose** (Tailwind `leading-normal`), **1.625 for the bio paragraph + blockquote** (`leading-relaxed` — extended reading ergonomics), **1.25 for headings + wordmarks** (`leading-tight`).
- **All-caps usage is restricted to UI eyebrows, CTA labels, and the cinematic wordmarks (`ABOUT`, `MICHELLE NGO`).** Prose, blockquote body, bio, press video titles, and ContactBlock rows are mixed-case.

### Two-stop gradient overlay tokens

Per Phase 5 D-05 (hero treatment), Phase 6 PBS section-zero (D-01) and /contact splash (D-11) reuse the **two-stop gradient overlay** shape:

```css
background: linear-gradient(180deg,
  rgba(0,0,0,0.55) 0%,
  transparent 30%,
  transparent 70%,
  rgba(0,0,0,0.55) 100%);
```

Top + bottom darken ≈ 55% black; middle 40% transparent. Same value as HeroAmbient. Tuned exactly to this constant by planner — no per-page deviation. `aria-hidden="true"` + `pointer-events-none` on the overlay element (matches existing).

## Motion & Interaction Contract

### Reduced motion (`prefers-reduced-motion: reduce`)

**Every animated surface MUST degrade gracefully.** Phase 6 contracts:

| Surface | Default motion | Reduced-motion behavior |
|---------|----------------|-------------------------|
| /about Act 1 ambient hero | PreviewLoop muted iframe autoplaying | Static producer-reel poster (REEL-04 unified codepath via `motion.svelte.ts`) |
| /pbs-american-portrait/ sections 1-18 | PreviewLoop muted iframe autoplaying (current ±1) | Static poster on every section (REEL-04 codepath) |
| /press 13 sections | NO iframes — always static posters by design (D-05) | Same — no degradation needed |
| /contact splash | NO iframe — always static poster by design (D-11) | Same — no degradation needed |
| Section-to-section scroll-snap | `scroll-snap-type: y mandatory` CSS native | CSS unchanged — pure CSS scroll-snap is accessible; motion-reduce does NOT disable scroll-snap (it's user-initiated motion, not auto-motion) |
| Chrome fade transitions | `motion-safe:transition-opacity duration-300` (TopNav) | `motion-reduce` variant suppresses transition — chrome state changes are instant |
| `▷ Watch` and outbound CTA hover-color change | `motion-safe:transition-colors duration-200` | `motion-reduce` variant suppresses transition — instant color swap on hover |

**Grep gate:** every `transition-*` utility in Phase 6 new code MUST be prefixed with `motion-safe:` (the Tailwind v4 variant pattern). Verified by lint rule extension.

### Scroll behavior

- **PBS landing + /press:** scroll-snap reel surface — `scroll-snap-type: y mandatory` on the `<ReelStage>` container; each section is `snap-start h-svh`. Inherits Phase 3 / Phase 4 patterns.
- **/about:** scroll is **natural, not snap** — Act 1 is h-svh but the page is NOT scroll-snap. Producer scrolls past ambient hero into bio at their own pace. Implementation: no `snap-type` on /about root; Act 1 = `h-svh`, Act 2 = natural-flow content below.
- **/contact:** scroll is **natural, not snap** — single h-svh splash above; Footer scrolls into view via natural document scroll below. No `snap-type` on /contact root.
- **/about Act 1 ambient hero pause:** subscribes to `pageVisibility.documentHidden` rune (Phase 5) — pauses when mobile menu opens or document.hidden flips true. Existing HeroAmbient contract.

### Focus management

- **Global `:focus-visible` double-ring** (Phase 1 D-05/D-08) applies to every interactive element added in Phase 6 — ContactBlock links, Footer links, PBS section-zero outbound, "See on PBS →" badges, /press `▷ Watch` CTAs. Zero per-component focus styling required (the global rule covers them).
- **Scroll-snap + keyboard nav:** PBS landing inherits Phase 4 NAV-02 keyboard nav (Arrow / PageUp / PageDown / Tab exits / Escape returns). /press inherits the same (it uses `<ReelStage>` or a sibling per Claude's Discretion).
- **/about Act 2 + /contact splash:** no scroll-snap → standard browser keyboard scroll (Arrow / PageDown). Tab order: TopNav → main content → Footer.

### Touch / pointer

- All buttons + links have a **minimum touch target of 44×44px** (WCAG 2.5.5 enhanced). Verify: `px-6 py-3` on pill buttons = 48×48 minimum; `px-3 py-1` on the small "See on PBS →" badge = 32×24 fails strict 44×44 but matches existing CategoryTag chip dimensions (existing Phase 3 pattern; acceptable on the cinematic-immersive reel where badge is secondary chrome, not primary nav).
- **No hover-required interactions on mobile** (REQUIREMENTS Out of Scope) — every hover effect (`hover:bg-*`, `hover:underline`) is decorative; the function works on tap.
