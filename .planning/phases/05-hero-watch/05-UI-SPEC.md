# Phase 5 — UI Design Contract

> Visual and interaction contract for the cinematic entry surface (`/`) and the cinematic playback surface (`/watch/[id]`). Generated by gsd-ui-researcher from 05-CONTEXT.md (D-01..D-17), 05-RESEARCH.md (Findings 1..11 + Recipes §1..§8), Phase 1 design tokens (D-05..D-13 in app.css), and Phase 3 carry-forward (REEL-04/REEL-05 overlay treatment). Verified by gsd-ui-checker against the 6 dimensions.

**Surfaces in scope:**

1. `<HeroAmbient />` on `/` — full-bleed `100svh` ambient producer reel (Vimeo `264677021`) silently autoplaying as background; centered MICHELLE NGO wordmark + tagline + `▷ PLAY REEL` pill CTA + bottom `↓` scroll-cue; two-stop gradient overlay for legibility.
2. `<WatchPlayer />` on `/watch/[id]` — letterboxed `aspect-video w-full max-h-svh` embed inside `bg-black min-h-svh` canvas; chrome (back button + metadata + rail heading) fades to `opacity-20` 600ms after `play` postMessage; fades back to `opacity-100` on `pause` / pointer-leave / idle-3s.
3. `<ContinueReelRail />` below `<WatchPlayer />` — pure CSS `scroll-snap-x mandatory` horizontal flex row of poster-only sibling cards; fractional-peek widths (`w-[70vw] sm:w-[40vw] md:w-[28vw] lg:w-[22vw]`); heading-is-link to `/work/[slug]`.
4. Back-nav from `/watch/[id]` — hash-only restoration (`/work#video={id}`) consumed in `<ReelStage>` `$effect` via `scrollIntoView({ block: 'start', behavior: 'auto' })`.

## Spacing Scale

Tailwind v4 default scale is 4px-based; Phase 5 uses these tokens exclusively. No custom spacing additions.

| Token | Value | Tailwind class | Phase 5 usage |
|-------|-------|----------------|---------------|
| xs | 4px | `p-1` / `gap-1` | Inline icon gap on `▷ PLAY REEL` (between glyph and label) |
| sm | 8px | `p-2` / `gap-2` | Compact gaps inside the back-button cluster |
| md | 16px | `p-4` / `gap-4` | Card padding inside `<ContinueReelRail>` cards; metadata block internal spacing |
| lg | 24px | `p-6` / `gap-6` | Hero overlay content stack vertical gap (wordmark ↔ tagline ↔ CTA) |
| xl | 32px | `p-8` / `gap-8` | Watch metadata block top padding (under player) |
| 2xl | 48px | `p-12` / `gap-12` | ContinueReelRail outer vertical padding (above/below the rail) |
| 3xl | 64px | `p-16` / `gap-16` | Watch route bottom whitespace below rail (cinematic breathing room) |

**Exceptions:**

- Hero scroll-cue `↓` glyph anchored at `bottom-10` (40px) — between `2xl` and `3xl`; Tailwind preset value retained for visual cue spacing per `_four` HeroPoster convention.
- ContinueReelRail card peek widths use viewport-percentage classes (`w-[70vw] sm:w-[40vw] md:w-[28vw] lg:w-[22vw]`) per CONTEXT D-11 — fractional-peek is the LOAD-BEARING affordance; NOT a multiple-of-4 token.
- Touch targets on hero CTA pill + watch back-button + rail cards: minimum 44px tap target (WCAG 2.5.5) — achieved via `py-3` (24px) + line-height + visual padding. Pill button declared `px-6 py-3` per RESEARCH Recipe §1.

## Typography

Phase 5 declares **4 sizes, 2 weights** (heading scale + body scale + label scale). Source family per role: display surfaces use `font-display` (Source Serif 4); UI chrome + body + labels use `font-sans` (Inter).

| Role | Family | Size | Weight | Line-height | Tailwind class | Phase 5 usage |
|------|--------|------|--------|-------------|----------------|---------------|
| Display (hero wordmark) | font-display | 48px → 72px (responsive) | 600 (semibold) | 1.1 | `text-5xl md:text-7xl font-display font-semibold tracking-[0.2em] leading-tight` | `MICHELLE NGO` wordmark on `/` hero |
| Heading (watch title, rail heading) | font-display | 28px → 36px (responsive) | 600 | 1.2 | `text-3xl md:text-4xl font-display font-semibold leading-snug` | `<h1>{video.title}</h1>` on `/watch/[id]`; `<h2>More in {category} →</h2>` on rail |
| Body (description, uploader · year) | font-sans | 16px | 400 (regular) | 1.5 | `text-base font-sans font-normal leading-relaxed` | Description paragraph on `/watch/[id]`; `{uploader} · {year}` metadata line |
| Label (CTA + chip + tagline + scroll-cue) | font-sans | 14px | 500 (medium) | 1.4 | `text-sm font-sans font-medium tracking-widest uppercase leading-snug` | `▷ PLAY REEL` CTA label; `▷ PLAY WITH SOUND` (carry-forward Phase 3); CategoryTag chip text; "Filmmaker & Producer" tagline; rail card title overlay |

**Locked rules:**

- Hero wordmark uses `tracking-[0.2em]` letter-spacing — cinematic register; matches `_four` hero wordmark treatment.
- All UPPERCASE labels (`▷ PLAY REEL`, `▷ PLAY WITH SOUND`, CategoryTag text) use `tracking-widest` (~0.1em) for readability of all-caps small text.
- Body line-height is `leading-relaxed` (1.625) on long-form description paragraphs (WCAG AAA 1.5+ minimum); display headings use `leading-tight` / `leading-snug` (1.1–1.3) for cinematic punch.
- No size between 16px (body) and 28px (heading) — keeps the scale tight (3 visual sizes + the display giant); rail card title is at 14px label scale.
- No font-weight other than 400 and 600 used in Phase 5. The 500 (medium) on labels is a Tailwind class but maps to Inter 500 woff2 already loaded in Phase 1 — keep declared.

## Color

Dark-only palette per PROJECT.md constraint (light-mode explicitly out of scope). Tokens defined in `src/app.css` `@theme` block (Phase 1 D-02, D-12).

| Role | Value (OKLCH) | Tailwind class | Phase 5 usage |
|------|---------------|----------------|---------------|
| Dominant (60%) — canvas | `oklch(0.16 0 0)` = `--color-neutral-950` | `bg-neutral-950` | Hero canvas before iframe loads; watch outer canvas (`bg-black` per D-06 OR `bg-neutral-950` — see "Watch canvas distinction" below); rail card placeholder background |
| Dominant (60%) — true black | `#000000` / `oklch(0 0 0)` | `bg-black` | Watch route outer wrapper per CONTEXT D-06 (`<div class="bg-black min-h-svh">`); letterbox bars (top/bottom OR left/right per Finding 8); the cinema-immersive register requires deeper black than `neutral-950` for letterbox stripes |
| Secondary (30%) — UI ink | `oklch(0.98 0 0)` = `--color-neutral-50` | `text-neutral-50` | Hero wordmark + tagline + CTA text; watch title + metadata when chrome NOT faded; rail heading + card titles; back-button label; scroll-cue `↓` glyph (at `text-neutral-50/60` for soft 60% opacity affordance) |
| Secondary (30%) — body text | `oklch(0.82 0 0)` = `--color-neutral-300` | `text-neutral-300` | Watch description paragraph; uploader · year metadata; rail card uploader overlay (softer than primary ink for hierarchy) |
| Secondary (30%) — disabled / faded chrome | `oklch(0.62 0 0)` = `--color-neutral-500` | `text-neutral-500` | Decorative dividers (`·` separator); inactive chrome opacity not used directly — fade uses `opacity-20` on `text-neutral-50` per D-07 |
| Accent (10%) — focus ring | `oklch(0.98 0.02 80)` (outer cream) + `oklch(0.16 0 0)` (inner dark) = `--ring-focus` / `--ring-focus-inner` | global `:focus-visible` | Every focusable Phase 5 element inherits automatically (no per-component opt-in) — Phase 1 D-05/D-08 contract |
| Accent (10%) — category accent | `var(--color-cat-{category})` (8 OKLCH hues per Phase 1 D-12) | `text-[var(--color-cat-{slug})]` + `ring-[oklch(from_var(--color-cat-{slug})_l_c_h/0.4)]` | CategoryTag chip on watch metadata (text color + ring color matching `categoryAccent.ts` Phase 4 helper); ONE category color per video — never combined |
| Accent (10%) — overlay gradient | `rgba(0,0,0,0.55)` stops at 0% + 100%; `transparent` 30%-70% | inline `style="background: linear-gradient(180deg, rgba(0,0,0,0.55) 0%, transparent 30%, transparent 70%, rgba(0,0,0,0.55) 100%);"` | Hero D-05 two-stop gradient — protects top + bottom text contrast; preserves center video clarity (Pitfall 20 mitigation) |
| Destructive | not used in Phase 5 | — | Phase 5 ships no destructive actions (no delete, no irreversible navigation, no form submission). N/A. |

**60/30/10 split:**

- **60% Dominant** — `bg-black` (watch route) + `bg-neutral-950` (hero pre-load canvas, rail card placeholder) cover the canvas across both surfaces; the video iframe itself dominates visually but is content not chrome.
- **30% Secondary** — `text-neutral-50` (primary ink for ALL UI text) + `text-neutral-300` (body/metadata) + the two-stop gradient overlay on hero.
- **10% Accent** — focus ring (Phase 1 global) + per-video category color on CategoryTag chip + the watch-route fade transition (chrome at `opacity-20` is itself the "accent" of presence-during-pause).

**Accent reserved for (explicit list — never "all interactive elements"):**

1. **Focus ring** — every focusable element via global `:focus-visible` (Phase 1 D-05).
2. **CategoryTag chip on watch metadata** — text color + ring-40 (40% alpha) using the video's specific category accent.
3. **CategoryTag chip on rail cards** — same treatment for consistency.
4. **Hero CTA hover state** — `hover:bg-neutral-50 hover:text-neutral-950` inverts to cream-on-dark (NOT a category accent — pure neutral inversion).

**Watch canvas distinction:** CONTEXT D-06 specifies `bg-black` for the watch route outer canvas (NOT `bg-neutral-950`) — the letterbox bars need to be deeper-than-neutral-950 to read as cinematic black-bars rather than dark-grey-bars. The hero canvas (which is fully covered by poster/iframe within 200ms of paint) uses `bg-neutral-950` as the pre-paint scrim. The rail card placeholder uses `bg-neutral-950` (cards never need true black; they sit on a `bg-black` canvas and the contrast with the card edge is the affordance).

## Interaction & Motion Contract

**Phase 5-specific interaction states beyond the spacing/typography/color tokens above.**

### Hero CTA pill

| State | Visual |
|-------|--------|
| Rest | `border border-neutral-50 text-neutral-50 bg-transparent rounded-full px-6 py-3` |
| Hover | `bg-neutral-50 text-neutral-950` — inverts to filled. `motion-safe:transition-colors duration-200`. |
| Focus-visible | Global double-ring (cream outer + dark inner, 2px each) — inherited automatically. |
| Active (pressed) | Browser-native depression; no extra style override. |
| Disabled | N/A — CTA is never disabled. (Cellular/LPM fallback shows the CTA over poster instead of over ambient reel — same visual.) |

### Hero deferred-load sequence (D-03, RESEARCH Recipe §1)

| t | State | Visual |
|---|-------|--------|
| 0ms | Poster eager-loaded via `<img loading="eager" fetchpriority="high">` | LCP first paint — gradient overlay + wordmark + tagline + CTA + scroll-cue all visible over poster |
| 0-1000ms | Awaiting `requestIdleCallback` / 1s timer / first pointer interaction (whichever first) | Same as t=0; user can interact with CTA + scroll-cue immediately |
| Trigger fires | PreviewLoop component mounts above poster (z-stack) | Iframe begins fetch; poster remains visible underneath as fallback |
| Iframe ready (postMessage `ready` or `play`) | Iframe video silently autoplays | Visual identical to poster moment (same first frame); transition is invisible — zero CLS per POL-03 |

### Watch chrome-fade state machine (D-07, RESEARCH Recipe §3)

| Event | Visual transition | Timing |
|-------|-------------------|--------|
| Mount / idle | `opacity-100 pointer-events-auto` on chrome group (back-button + metadata + rail heading); `motion-safe:transition-opacity duration-300` | Initial paint |
| `play` postMessage received | After 600ms grace, chrome → `opacity-20 pointer-events-none`; `motion-safe:transition-opacity duration-500` | 600ms grace prevents flash-fade on mid-click; 500ms fade-out is slower than fade-in to feel cinematic |
| `pause` postMessage received | Chrome → `opacity-100 pointer-events-auto`; `motion-safe:transition-opacity duration-300` | Immediate (no grace) |
| Pointer-leave canvas bounding rect (while playing) | Chrome → `opacity-20 pointer-events-none`; 500ms | Immediate |
| Pointer-move anywhere on canvas (while chrome faded) | Chrome → `opacity-100`; 300ms; idle-3s timer resets | Immediate |
| Idle-3s timer elapses (no pointer-move while playing) | Chrome → `opacity-20 pointer-events-none`; 500ms | After 3000ms of no movement |
| `touchend` on canvas (mobile) | Chrome → `opacity-100`; 300ms; idle-3s timer arms | Immediate (mobile recovery — touch devices don't fire `pointerleave` on lift) |
| `prefers-reduced-motion: reduce` | Transitions removed (`motion-safe:` variants are no-op); state still toggles `opacity-20`/`opacity-100` but the change is instant | Per RESEARCH §Deferred — no special handling; opacity binary change is acceptable for reduced-motion users |

**Locked rule:** Chrome fade uses `opacity-0 → opacity-20` (not `opacity-0`) — at 20% the chrome remains discoverable to screen readers and visible to sighted users hunting for it, but recedes from the cinematic experience. `pointer-events-none` prevents accidental clicks on faded chrome. NEVER `display: none` / `visibility: hidden` (would hide from SR — Phase 4 D-11 / Pitfall 8 carry-forward).

### ContinueReelRail scroll

| Trigger | Behavior |
|---------|----------|
| Mouse wheel (desktop, horizontal-capable) | Native horizontal scroll; `scroll-snap-type: x mandatory` snaps to `snap-start` on each card |
| Touch swipe (mobile / trackpad) | Native momentum scroll; snaps |
| Keyboard arrow keys (focus inside rail) | Native browser behavior — arrow keys scroll the overflow container |
| Tab key | Tabs through each card link in DOM order; focus ring visible |
| Card hover (desktop) | Optional subtle `scale-[1.02]` or `opacity` lift — Claude's Discretion in plan-phase; default to NO hover effect for cinematic minimalism. Card link IS the affordance; no hover overlay. |
| Card focus-visible | Global double-ring (cream + dark) inherits — no per-card focus style. |
| Card click | SvelteKit client-side nav to `/watch/{id}`; preserve hash on origin URL (no hash on rail clicks) |

### Hash restoration (D-15)

| Trigger | Behavior |
|---------|----------|
| `/work#video={id}` direct paste | Page renders; `<ReelStage>` `$effect` fires once `sectionRefs.length === videos.length`; finds matching ref; `scrollIntoView({ block: 'start', behavior: 'auto' })` — INSTANT, no smooth-scroll animation per D-15 |
| Back-nav from `/watch/[id]` via browser back gesture | Same — hash preserved; restoration fires on `<ReelStage>` mount |
| `/work#video={id}` where id NOT in current filtered set | No-op; land at top of reel (page scroll position 0) |
| `/work#video={id}` under `prefers-reduced-motion` | Same — instant scroll is the universal default (no smooth-scroll fallback question) |

### Cross-cutting motion rules

- All transitions wrapped in `motion-safe:` variants — users with `prefers-reduced-motion: reduce` see instant state changes (Phase 1 carry-forward, WCAG 2.3.3 compliance).
- Hero auto-mount under reduced-motion: poster-only render per CONTEXT D-04 unified codepath — no iframe ever attaches.
- Watch route autoplay-with-sound is PLAYBACK not decorative motion → exempt from WCAG 2.3.3 per RESEARCH §Deferred ("autoplay is playback not motion-decoration").
